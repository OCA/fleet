To see the telemetry on the map, go to *Fleet > Configuration > Telemetry >
Telemetry Map*. Each vehicle route is drawn as a line and colored per day.

Use the legend in the top right corner to show or hide routes by vehicle or
by day.

The search bar on top of the map filters the points by period: today
and yesterday (default), today, yesterday, this week, last week, this
month, last month or this year. Only one period is active at a time.
The list view of the telemetry is paginated.
