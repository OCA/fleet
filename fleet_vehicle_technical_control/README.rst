This module extends Fleet vehicles with technical control tracking.

It adds a Technical Control page on the vehicle form where users can
define the control frequency in months, see the last and next technical
control dates, and review the history of completed controls.

**Table of contents**

.. contents::
   :local:

Configuration
=============

Fleet managers can set the control frequency directly on each vehicle
from the Technical Control page using the
``Technical Control Every (Months)`` field. The default frequency is 12
months.

Usage
=====

To configure technical control planning:

- Go to Fleet > Vehicles.
- Open a vehicle.
- Open the Technical Control page.
- Fill Technical Control Every (Months).

To record a completed technical control:

- Click Technical Control Done.
- Fill the control date and result.
- If the result is Not Valid, fill the comment.
- Optionally upload an attachment.
- Save the form.

A new line is added to the history. The vehicle's last technical control
date is computed from the most recent history line, and the next
technical control date is computed from that date and the configured
frequency.
